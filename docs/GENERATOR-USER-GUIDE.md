# 📚 Guide Utilisateur - Générateur Musical MED-MNG

## 🎵 Introduction

Le **Générateur Musical MED-MNG** transforme vos contenus éducatifs médicaux en chansons mnémotechniques personnalisées pour faciliter l'apprentissage et la mémorisation.

---

## 🚀 Démarrage Rapide

### Étape 1 : Accéder au Générateur

1. Connectez-vous à votre compte MED-MNG
2. Cliquez sur **"Générateur"** dans le menu
3. Vous arrivez sur `/generator`

### Étape 2 : Sélectionner le Type de Contenu

Trois types disponibles :

#### 🎯 EDN (Items de Connaissances)
- **Usage** : Items UNESS officiels
- **Exemples** : IC-001, IC-002, etc.
- **Rangs** : A (fondamental) ou B (approfondi)

#### 🏥 ECOS (Cas Cliniques)
- **Usage** : Scénarios cliniques complets
- **Format** : Situations pratiques

#### 📋 OIC (Objectifs Pédagogiques)
- **Usage** : Objectifs d'apprentissage
- **Format** : Compétences ciblées

### Étape 3 : Choisir l'Item

1. Cliquez sur le sélecteur d'items
2. Recherchez par code (ex: IC-290)
3. Sélectionnez l'item désiré
4. Le titre s'affiche automatiquement

### Étape 4 : Sélectionner le Rang

**Pour EDN uniquement :**

- **Rang A** : Connaissances fondamentales
  - Concepts de base
  - Définitions essentielles
  - Signes cliniques principaux

- **Rang B** : Connaissances approfondies
  - Détails diagnostiques
  - Traitements spécialisés
  - Cas complexes

- **Rang AB** : Combinaison A + B
  - Contenu complet
  - Progression pédagogique

### Étape 5 : Choisir le Style Musical

**Styles disponibles :**

| Style | Tempo | Ambiance | Recommandé pour |
|-------|-------|----------|-----------------|
| **Lofi Piano** | Calme | Relaxant | Révisions tranquilles |
| **Pop Upbeat** | Rapide | Énergique | Mémorisation active |
| **Jazz Smooth** | Modéré | Sophistiqué | Concentration |
| **Classical** | Variable | Élégant | Apprentissage profond |
| **Ambient** | Lent | Méditatif | Compréhension |
| **Electronic Chill** | Modéré | Moderne | Sessions longues |

**💡 Conseil :** Variez les styles pour éviter la monotonie et stimuler différentes zones cérébrales.

### Étape 6 : Générer la Musique

1. Cliquez sur **"Générer Musique"**
2. Patientez 2-3 minutes (génération en cours)
3. Une notification apparaît quand c'est prêt

**Barre de progression :**
- 🔵 Génération en cours...
- 🟢 Rang X prêt ! Cliquez pour écouter

---

## 🎧 Écouter et Gérer

### Lecteur Audio

Une fois généré :

1. **▶️ Écouter** : Cliquez sur le bouton "Écouter"
2. **⏸️ Pause** : Cliquez à nouveau pour mettre en pause
3. **📚 Bibliothèque** : Ajoutez à votre bibliothèque

### Contrôles du Lecteur

- **Volume** : Ajustez avec le curseur
- **Progression** : Barre de lecture interactive
- **Boucle** : Activez pour répéter
- **Vitesse** : 0.5x à 2x (réglable)

---

## 📚 Bibliothèque Musicale

### Ajouter à la Bibliothèque

1. Cliquez sur **"Ajouter à Bibliothèque"**
2. Confirmez l'ajout
3. Accédez via `/library`

### Organiser

- **Playlists** : Créez des playlists thématiques
- **Favoris** : Marquez vos préférées
- **Recherche** : Filtrez par item, rang, style
- **Tri** : Date, alphabétique, durée

---

## ⚡ Conseils d'Utilisation

### Pour une Mémorisation Optimale

1. **Écoute Active** (première fois)
   - Suivez les paroles
   - Notez les concepts clés
   - Identifiez les mnémotechniques

2. **Écoute Passive** (révisions)
   - En fond pendant révisions
   - Pendant trajets
   - Avant de dormir

3. **Répétition Espacée**
   - Jour 1 : 3 écoutes
   - Jour 3 : 2 écoutes
   - Jour 7 : 1 écoute
   - Jour 30 : 1 écoute

### Styles par Contexte

| Contexte | Styles Recommandés |
|----------|-------------------|
| Révisions intensives | Pop Upbeat, Electronic |
| Compréhension profonde | Classical, Jazz |
| Avant examen | Lofi, Ambient |
| Sessions longues | Lofi, Electronic Chill |
| Mémorisation rapide | Pop, Electronic |

## 🔧 Dépannage

### La génération ne démarre pas

**Solutions :**
1. Vérifiez tous les champs (type, item, rang, style)
2. Actualisez la page (F5)
3. Déconnectez/reconnectez-vous
4. Contactez le support

### La génération prend trop de temps

**Normal :**
- Temps moyen : 2-3 minutes
- Maximum : 5 minutes

**Si > 5 minutes :**
1. Vérifiez votre connexion internet
2. Consultez `/monitoring` pour voir le statut
3. Réessayez avec un autre style

### L'audio ne se lit pas

**Solutions :**
1. Vérifiez le volume (navigateur + système)
2. Testez avec un autre navigateur
3. Videz le cache (Ctrl+Shift+Del)
4. Vérifiez les bloqueurs de publicités

### La qualité audio est mauvaise

**Solutions :**
1. Utilisez un casque/écouteurs de qualité
2. Vérifiez votre connexion (3G+ recommandé)
3. Essayez le style "Classical" pour meilleure qualité

## 🎯 Cas d'Usage

### Cas 1 : Préparation ECN

**Objectif :** Réviser IC-290 (Ulcère gastrique)

1. Sélectionner **EDN** > **IC-290** > **Rang AB**
2. Choisir **Lofi Piano** (concentration)
3. Générer
4. Écouter 3x le premier jour
5. Ajouter à playlist "Gastro-entérologie"
6. Réviser avec répétition espacée

### Cas 2 : Session de Révision Intensive

**Objectif :** Réviser 10 items en 2h

1. Préparer playlist avec 10 items variés
2. Utiliser **Pop Upbeat** pour énergie
3. Écouter en boucle pendant révisions écrites
4. Alterner lecture active/passive
5. Marquer favoris pour items difficiles

### Cas 3 : Révisions Avant Examen

**Objectif :** Réviser dernière minute

1. Playlist "Essentiels Examen"
2. Style **Ambient** (calme)
3. Écoute passive en fond
4. Focus sur items faibles
5. 1h avant : écoute active des favoris
