## 🚀 Utilisation

### Installation

Tous les composants sont déjà installés dans le projet. Importez-les directement :

```tsx
import { Button } from '@/components/ui/button';
import { Card, CardHeader, CardTitle, CardContent } from '@/components/ui/card';
```

### Design System

Tous les composants utilisent les **tokens sémantiques** définis dans `index.css` :

- `--primary`, `--secondary`, `--accent` pour les couleurs
- `--background`, `--foreground` pour les surfaces
- Support natif du **dark mode**
- Variants cohérents via `class-variance-authority`

### Accessibilité

Chaque composant est construit avec les meilleures pratiques d'accessibilité :
- Utilisation de Radix UI pour les composants complexes
- Support complet du clavier
- ARIA attributes appropriés
- Tests d'accessibilité via addon a11y

export const ComponentCard = ({ title, description, link, icon }) => (
  <a
    href={link}
    style={{
      display: 'block',
      padding: '1.25rem',
      borderRadius: '0.5rem',
      border: '1px solid hsl(var(--border))',
      textDecoration: 'none',
      color: 'inherit',
      transition: 'all 0.2s',
      background: 'hsl(var(--card))',
      cursor: 'pointer'
    }}
    onMouseEnter={(e) => {
      e.currentTarget.style.borderColor = 'hsl(var(--primary))';
      e.currentTarget.style.transform = 'translateY(-2px)';
      e.currentTarget.style.boxShadow = '0 4px 12px hsl(var(--primary) / 0.15)';
    }}
    onMouseLeave={(e) => {
      e.currentTarget.style.borderColor = 'hsl(var(--border))';
      e.currentTarget.style.transform = 'translateY(0)';
      e.currentTarget.style.boxShadow = 'none';
    }}
  >
    <div style={{ fontSize: '2rem', marginBottom: '0.5rem' }}>{icon}</div>
    <h3 style={{ margin: '0 0 0.5rem 0', fontSize: '1rem', fontWeight: 600 }}>{title}</h3>
    <p style={{ margin: 0, fontSize: '0.875rem', opacity: 0.8, lineHeight: 1.5 }}>{description}</p>
  </a>
);
